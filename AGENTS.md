# DevDesk – AI Coding Agent Specification

This file is the master specification and implementation contract.

The full product requirements, architecture, technology stack, phases, and agent rules are defined in the original project specification provided by the user.

**Key mandatory rules for agents:**

1. Work autonomously – create and modify real source files.
2. Implement one phase at a time.
3. No SQL / SQLite / web UI / Electron / unnecessary dependencies.
4. Keep UI separate from business logic.
5. Use keyring for credentials; never store tokens in JSON.
6. Maintain `IMPLEMENTATION_PLAN.md`.
7. Run tests after each phase.
8. Prefer a working, simple application over over-engineering.

Refer to the complete specification document for all details.
