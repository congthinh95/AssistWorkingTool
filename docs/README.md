# DevDesk Documentation Index

This directory contains the operational and technical documentation for the DevDesk desktop assistant.

## Structure

- `user-guide/` - end-user instructions, workflows, and daily usage steps
- `architecture/` - service and module architecture overview
- `design/` - product and interaction design references
- `build/` - packaging, build process, and release notes

## Quick access

- Install and run: `docs/user-guide/README.md`
- System architecture: `docs/architecture/README.md`
- Design direction: `docs/design/README.md`
- Build / packaging: `docs/build/README.md`

## Project purpose

DevDesk is a local-first desktop dashboard for developers. It aggregates Jira issues, review requests, working time tracking, and quick access tools into one tray-based experience.
